Description complète du projet (résumé “spécification”)
	•	App Android Flutter qui détecte l’ouverture d’une app “scroll” choisie (TikTok/IG/YT…)
	•	Affiche un overlay “Pause 2 secondes” avec :
	•	une raison (ennui/stress/procrastination…)
	•	un choix : “OK 5 minutes” ou “Micro-action 30s”
	•	Enregistre tous les événements localement
	•	Affiche Dashboard + Stats (7 jours) + Settings

Design (Apple-like)
	•	1 police (SF Pro/Inter), espace, cartes radius 18, fond gris très clair, texte near-black, 1 accent bleu doux
	•	UI minimal : pas de bordures fortes, micro-copy bienveillante
