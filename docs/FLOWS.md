
## Navigation
Tab bar : Home | Actions | Stats | Profil

## Flow 0 — Onboarding
1) Welcome (valeur)
2) Sélection des apps à contrôler
3) Objectif (minutes/jour + option “pas après HH:MM”)
4) Niveau de friction (Soft/Medium/Hard)
5) Permissions Android (Usage Access + Draw over other apps)
6) Fin : “Tout est prêt”

## Flow 1 — Usage (Friction Screen)
Déclencheur : l’utilisateur ouvre une app “ciblée”
1) Overlay “Pause 2 secondes”
2) Question : “Pourquoi tu ouvres ?” (chips)
3) Choix :
   - “OK 5 minutes” (session limitée)
   - “Micro-action 30s”
4) Enregistrement : app + timestamp + raison + décision

## Flow 2 — Session courte
1) Démarre un timer (5 min)
2) Notification/overlay à la fin :
   - “Stop”
   - “+2 min” (max 2 fois)
3) Log de session (durée effective)

## Flow 3 — Micro-action
1) Afficher 1 action (respiration / eau / étirements / mini-rangement / note rapide)
2) Bouton “Démarrer” (timer si nécessaire)
3) “Terminé” -> autoriser l’ouverture de l’app

## Flow 4 — Dashboard
Home :
- minutes aujourd’hui
- ouvertures aujourd’hui
- streak
- raccourci “Focus 25 min” (optionnel MVP)
- cartes insights : heure critique + raison #1

## Flow 5 — Stats
Stats :
- 7j / 30j
- tendance minutes/jour
- heures de craquage (barres/heatmap simple)
- top raisons
- “gains” : temps économisé estimé

## Flow 6 — Profil / Paramètres
- Apps ciblées
- Objectif (minutes, horaires)
- Niveau friction
- Micro-actions : activer/désactiver
- Exports (plus tard)
- Aide / FAQ
